Sal's DevOps Capstone Pipeline

A commit to main is built by Jenkins, pushed to Docker Hub, pulled by the app server, restarted as a container, and verified with a smoke test.

Deployment Flow

Running from Docker Hub
✓
GitHub Main Source change
✓
Jenkins Build Pipeline job
✓
Docker Image Commit SHA tag
✓
Docker Hub Push artifact
✓
App Server Pull and restart
✓
Smoke Test HTTP verified

Infrastructure

Terraform creates AWS resources and the Docker Hub repository.

Configuration

Ansible configures Jenkins, credentials, worker access, and the deploy job.

Delivery

Jenkins deploys an immutable image tag and verifies the running container.
